## Offseason robot

After the season we designed and built a second Rebuilt robot for WARP in August 2026. It drives on swerve modules and has an intake arm with carbon fibre rollers, a polycarbonate hopper that slides out when the intake drops, and a flywheel shooter. Two cameras let it line up on the hub and the trench automatically.

The code for the offseason robot is [on GitHub](https://github.com/CurtinFRC/2026-Offseason).
